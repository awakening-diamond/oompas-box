## OOMPAS Box 1.1.0

- Updates itself: the app checks GitHub for new versions (Windows installs on restart; Mac shows a download link). Help → Check for Updates.
- MiSTer scripts update through update_all (see README: "Keeping it up to date").
- IPTV: Languages filter (from iptv-org's language data), combines with Countries and Categories.
- IPTV: "Check which channels play" tests every channel from your PC; "Hide channels that don't play".
- IPTV: cleaner channel names ("(720p)", "[Geo-blocked]" shown as tags).
- Picture shapes (Z): Fit, Trim bars, Fill window, Stretch. Window Size menu; the window keeps its size.
